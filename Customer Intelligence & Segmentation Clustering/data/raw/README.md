# Raw data provenance

Download `Mall_Customers.csv` from the Kaggle dataset below and place it in this directory:

https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

The repository does not commit raw Kaggle data. If the file is missing, `python -m src.pipeline` generates a deterministic demo dataset and labels the resulting artifacts as demo data.
